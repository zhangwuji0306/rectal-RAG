# AGENTS.md

## Purpose
RAG document ingestion pipeline: retrieves papers, converts academic papers (PDF) into clean Markdown, and stores them in a retrieval knowledge base. Local Git repository present. Windows + Git Bash, Python 3, Chinese filenames throughout.

## Key directories
- 直肠癌文献爬取/ — managed upstream retrieval/downloader project (NBIB, task queue, reports, and PDF corpus); agents may maintain its scripts and state within this workspace
- `papers/` — containing downstream PDF inputs; `papers/索引信息.csv` is a legacy compatibility copy (canonical metadata is `直肠癌文献爬取/索引信息.csv`)
- `converted/` — flat output of `.md` files (never nested); `converted/已入库/` — archive of ingested md (moved after RAG ingestion; top-level `converted/` only holds not-yet-ingested files); `mucinous/` — MAC corpus copies (legacy phase artifact, kept as-is); `flash-failed/` — sources that failed conversion
- `index/` — vector search: `build_index.py` (chunk + embed + store), `retrieve.py` (query), `reconcile_manifest.py` (rebuild manifest from Chroma), `manifest.json`；另有 `bench.py` / `test_chunking.py`（编码与分块基准）、`evaluate_retrieval.py`（检索评估，配 `evaluation/`）。`chroma_db/` 向量实库（2026-09-03 复位，见「本地向量库位置与恢复」）
- `.model-cache/BAAI__bge-m3/` — local bge-m3 model copy (must exist before build_index/retrieve run)
- `.venv/` — Python venv; always run Python via `.venv/Scripts/python`
- `.claude/batch_convert.py` — conversion script (supports parallel RAG ingestion, see Commands); `.claude/conversion-tracker.json` — conversion state (don't hand-edit)
- `.claude/tmp/` — analysis scripts: `analyze.py` (classification → `mapping.json`), `gen_pmid_mapping.py` (PMID batch metadata → `mapping_pmid.json`, from `直肠癌文献爬取/索引信息.csv`), `gen_excel.py` (report → root `MAC文献分类与转换报告.xlsx`), `sync_mucinous.py`, `final_check.py`；另含备份目录（勿删）：`chroma-backups/`（向量库合规备份/离线副本）、`manifest-backups/`、`crawler-backups/`、`github-backups/`（代码发布用远端仓备份）
- `tests/` — 流水线离线回归测试 `test_pipeline.py`（PDF 校验 / 队列刷新 / 索引替换顺序）
- `evaluation/` — 检索评估：人工标注 qrels `queries.jsonl`（模板 `queries.example.jsonl`）及用法说明 `README.md`
- `docs/` — `数据合规与发布清单.md`：语料与向量库的合规边界、发布前检查清单

## Vector index (RAG retrieval)
```bash
.venv/Scripts/python index/build_index.py            # incremental (sha256-based)
.venv/Scripts/python index/build_index.py --force    # full rebuild
.venv/Scripts/python index/retrieve.py "query" [-k 8] [--mac-only] [--json] [--device cpu|cuda]
.venv/Scripts/python index/reconcile_manifest.py --dry-run  # validate manifest against Chroma
.venv/Scripts/python index/reconcile_manifest.py             # reconcile manifest atomically (backs up old file)
```
- Indexes all Markdown in `converted/` and `converted/已入库/`, not just `mucinous/`; archive moves keep the same source filename and are idempotent. Chunks carry metadata (title/year/journal/doi/mac/license) from `.claude/tmp/mapping.json` (MAC corpus) + `.claude/tmp/mapping_pmid.json` (PMID batch, generated by `gen_pmid_mapping.py`; alias table in build_index.py links ESGAR parts + supplementary files).
- `manifest.json` is a per-source SHA-256/chunk ledger. It can be reconciled from the actual Chroma `papers` collection with `index/reconcile_manifest.py`; do not run concurrent Chroma writers, because stale in-memory manifests can overwrite newer entries.
- Chunks: passage-v2, heading-aware, ~800 tokens, overlap 80, min 16 tokens; bge-m3 (normalized, cosine via Chroma).
- D2 正式答案须由本机逐项人工确认放行。Evidence Pack 的外传须有明确的数据范围与授权。

### Reuse from another project (same machine, no copying)
`index/rag_core.py` is the importable core (paths default to writing-rag, overridable via `--db/--model` in CLI or args in code). Other projects query the live index directly:
```python
import sys
sys.path.insert(0, r"E:\writing-rag\index")
from rag_core import retrieve, dedupe_by_doi, summary_list

hits = retrieve("mucin pool prognosis", k=8, mac_only=True)
refs = dedupe_by_doi(hits)      # merge same-DOI hits -> literature level
for r in summary_list(refs):    # title/journal/year/doi/authors/mac/sections/n_hits
    print(r["title"], "|", r["doi"])
```
- Must run under `E:\writing-rag\.venv\Scripts\python` (deps: sentence-transformers, chromadb).
- Cross-machine transfer of private corpus/model/index requires explicit authorization; it is outside the code allowlist. Keep DB, paired manifest, ready marker and model identity together when authorized.
- Different corpus: requires an explicit implementation task; current `build_index.py` does not expose `--converted` or `--model`. Current remediation evidence is recorded in `整改手册/docs/reviews/remediation-package-handoff.md`; custom targets require paired manifests and the existing preflight/writer boundaries.

## Commands
```bash
PYTHONIOENCODING=utf-8 python .claude/batch_convert.py   # convert new papers (idempotent)
# Flags:
#   --max-run-minutes <n>  stop after finishing the current file once n minutes elapsed
#   --delete-source        delete the source PDF right after a successful conversion
#   --ingest               parallel RAG ingestion (chunk+embed+store) of converted md
#                          (pre-scans converted/ for un-ingested files, then ingests
#                          each new conversion live; ingested md archived to 已入库/)
#   --ingest-only          ingest only, no conversion
#   --ingest-live-only     skip pre-scan; only ingest files converted this run
#   --ingest-limit <n> / --convert-limit <n>   test caps
# Requires MINERU_TOKEN env for extract mode (>10MB or >20 pages, or flash fallback).
#   Set MINERU_TOKEN in the process environment only; never write the token to files or logs.
#   (this project is kept fully offline — never upload project data)
python .claude/tmp/gen_pmid_mapping.py                  # regenerate mapping_pmid.json from 直肠癌文献爬取/索引信息.csv
python .claude/tmp/sync_mucinous.py                      # copy converted MAC md -> mucinous/ (idempotent)
.venv/Scripts/python tests/test_pipeline.py               # 离线回归测试（tests/，unittest）
.venv/Scripts/python index/evaluate_retrieval.py --qrels evaluation/queries.jsonl --k 5,10   # 检索评估（qrels 编制见 evaluation/README.md）
```
文献爬取子项目：当前入口与支持边界见 `直肠癌文献爬取/AGENT.md`。不再以 `12→03→13→11` 多批次 SQLite 链作为默认操作；需要兼容迁移时单独明确任务范围。A 部分跨模块当前问题见 `ABCD整改审查意见.md` 第 3 节，P05 收口合同见第 5 节，生产 metadata 状态以 canonical SQLite 为准。

## 用时估算（实测基准）
全量转换+入库（flash/extract/兜底重试混合，入库并行进行）实测平均：
- 小文件批（median ~0.7 MB，2026-08-21/22）：37–46 s/文件
- 大文件批（median ~1.4 MB，2026-08-23）：52 s/文件
- 加权平均：45.8 s/文件；入库-only：34 s/文件
估算：总时长(分) ≈ 文件数 × 对应平均秒数 ÷ 60；>10 MB extract 大文件按 ×2 计；另加 ~10% 兜底重试余量。文件批特征越接近哪一档就取哪一档。
运行监测约定：启动后预估窗口内不监控，超时 ≤30 分钟不打扰；窗口结束由 agent 自动汇报。

## Gotchas
- NETWORK (this machine): PyPI official CDN is throttled (~30 KB/s) — install with `-i https://mirrors.aliyun.com/pypi/simple/`; huggingface.co is blocked — use `HF_ENDPOINT=https://hf-mirror.com` or the local `.model-cache/` copy; ModelScope is unreachable.
- Conversion idempotent by output stem; `flash-extract` (free, ≤10 MB / ≤20 pages) auto-retries once with `extract` mode (needs `MINERU_TOKEN`); files >10 MB go straight to `extract`.
- Ingestor pre-scan can race with the first live conversions on cold start (slow model load → pre-scan catches a just-created md → duplicate enqueue). Harmless since the 2026-08 fix (missing-file skip in `_ingest_one`), but prefer `--ingest-live-only` whenever `converted/` top-level is empty.
- Always prefix Python runs with `PYTHONIOENCODING=utf-8` (Chinese filenames/CSV).
- Git Bash heredocs mangle backslashes — write Python scripts to files instead of `python - <<EOF` when regex/escaping matters.
- Known intentional gaps (do not re-flag): 16 refs without PDFs (skip); `papers/XRLR7M9W` Melis 2010 is a confirmed duplicate of `CL55BBYQ` (keep, never convert); 4 orphaned old conversions in `converted/` (keep).
- CSV storage keys are 8-char IDs found inside `storage\<key>\` paths in the `File Attachments` column (CSV `Key` column differs from storage key).
- When extracting reference lists from the user's Word docs, take the LAST consecutive numbered block (some docs number body items too).
- 向量库不在 `index/chroma_db` 时，`retrieve.py`/`rag_core` 和有现存 manifest 的普通增量构建均应报错 —— 先按「本地向量库位置与恢复」处理并验证再运行；`.claude/tmp/chroma-backups/` 是合规备份目录，勿删。
